# Discord Activity

Shows DeepPlay as your activity on Discord, with the game you're playing, its box art and how long you've been playing: Xbox Cloud Gaming, GeForce NOW, Xbox Remote Play and PC Streaming. Sign in with your Discord account by QR code and it works straight from your PS3, no PC needed, or let DeepPlay Companion pass it to Discord on your PC. Turn it off any time.

| | |
| --- | --- |
| Version | 1.11 |
| Publisher | DeepPlay |
| Needs | A Discord account (or DeepPlay Companion on your PC) |
| Kind | Social, Discord |

Install it on the PS3 from DeepHub, DeepPlay's app store. These files are made by `publish-plugin.ps1` in the DeepPlay source.
