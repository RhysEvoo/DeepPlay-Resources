# Boosteroid

Sign in to Boosteroid with a QR code on your phone, then browse and search the games in your Boosteroid library. Playing them on the PS3 comes in an update. Not made by or affiliated with Boosteroid. Built on what the open-source ZERODROID client worked out.

| | |
| --- | --- |
| Version | 0.3 |
| Publisher | DeepPlay |
| Needs | A Boosteroid account with a subscription |
| Kind | Streaming, Cloud |

Install it on the PS3 from DeepHub, DeepPlay's app store. These files are made by `publish-plugin.ps1` in the DeepPlay source.
