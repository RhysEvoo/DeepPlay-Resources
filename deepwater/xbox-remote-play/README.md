# Xbox Remote Play

Stream your Xbox Series X|S or Xbox One straight to your PS3. Wake your console from the couch, pick up where you left off and play with your PS3 controller, all over your own network.

| | |
| --- | --- |
| Version | 1.5 |
| Publisher | DeepPlay |
| Needs | An Xbox on the same network, with remote features on |
| Kind | Streaming, Xbox |

Install it on the PS3 from DeepPlay Plugins. These files are made by `publish-plugin.ps1` in the DeepPlay source.
