# CloudMoon

Browse and search the mobile games CloudMoon streams from cloud Android phones (Roblox, Genshin Impact and more), with CloudMoon's free play time as a guest. Playing them on the PS3 comes in an update. Not made by or affiliated with CloudMoon.

| | |
| --- | --- |
| Version | 0.3 |
| Publisher | DeepPlay |
| Needs | Nothing: CloudMoon's free play time, as a guest |
| Kind | Streaming, Cloud, Mobile |

Install it on the PS3 from DeepHub, DeepPlay's app store. These files are made by `publish-plugin.ps1` in the DeepPlay source.
