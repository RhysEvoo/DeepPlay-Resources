# Xbox

Browse the games you can stream with Xbox Cloud Gaming and add them to your library, play them, see your Gamerscore and membership, and send and receive messages with your Xbox friends, all on your PS3. Link a Microsoft account to your DeepPlay user to start. Not made by or affiliated with Microsoft.

| | |
| --- | --- |
| Version | 0.8 |
| Publisher | DeepPlay |
| Needs | A Microsoft account, linked to your DeepPlay user |
| Kind | Cloud, Xbox, Social |

Install it on the PS3 from DeepHub, DeepPlay's app store. These files are made by `publish-plugin.ps1` in the DeepPlay source.
